# Gauche

Planned C++20 port of the original Rust Gauche prototype in the neighboring
`gauche-rs` repository. The goal is a close port of the playable game and its
look, built with the direct C++ game structure of Adventures with Chickens and
the current SDL3/Gubsy host and asset patterns of `splonks-cpp`.

No game code has been ported yet. See [the port plan](docs/PORT_PLAN.md).
